# ジェットコースター工房

線路パーツをつないで自分だけのコースを作り、試運転を楽しむブラウザーゲームです。HTML・CSS・JavaScriptだけで動作します。

## 起動方法

```bash
cd /workspaces/my-first-app
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。

## 遊び方

- 「直線」「上り坂」「下り坂」「山」「谷」「左カーブ」「右カーブ」「ループ」からパーツを選び、「パーツを追加」でコースを伸ばします。
- 「ひとつ戻す」で最後のパーツを取り消し、「作り直す」で最初の状態に戻せます。
- 「試運転する」でトロッコに乗った一人称視点のコースを走ります。線路には遠近感がつき、坂に合わせて景色が上下します。試運転後にコースの長さ、最高速度、ライド評価が表示されます。
- 画面上部の音声ボタンまたは `M` キーでBGMと効果音を切り替えます。

BGMは反復する打楽器と徐々に厚くなる旋律のボレロ風オリジナル曲です。ブラウザーの制限により、最初の操作後に再生が始まります。景色の色も時間とともに少しずつ変化します。
